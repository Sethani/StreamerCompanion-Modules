# Module catalogue

`modules.json` is the live, machine-readable index. Companion reads it using the GitHub Contents API. Each package URL points to an immutable individual release in this repository, such as `spotify-v2.0.1`.

This file is maintained by the source project's single-module publisher. Entries are generated from module manifests; do not duplicate source code or manually synchronize a second catalogue. A publication changes only the selected entry after its release asset has been uploaded and verified.
